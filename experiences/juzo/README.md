# OrthoServ × Juzo demo store

Buildless HTML/CSS/JS. Serve this folder using a local static web server, then open index.html through that server; JSON catalog loading requires HTTP.

Includes approved leg motion concept, original OrthoServ logo and official Juzo logo, six manufacturer-photo products, filters/search, hash-routed product pages, sizing help, enquiry list with quantities/removal and browser-local persistence, and a demo confirmation that sends nothing. No payment or order backend.

All catalog items are demonstration selections, not confirmed local inventory. No invented prices, compression classes, size chart or stock status. Refer to ASSET-SOURCES.md and products.json. Hero is AI-generated; actual product photos are Juzo-owned.
